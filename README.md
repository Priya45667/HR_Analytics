# HR_Analytics
This dashboard was developed as part of my learning journey in Data Analytics to understand employee attrition patterns and HR performance metrics using Power BI.

Project Overview-

This project focuses on analyzing employee data to identify attrition trends and workforce patterns using Power BI.
The dashboard helps HR professionals monitor employee attrition and understand the factors influencing employee retention.

Objective-

Analyze employee attrition
Understand workforce demographics
Identify departments with higher attrition
Support HR decision-making through interactive dashboards

Tools Used-

Microsoft Excel
Power BI

Dashboard Features-

Overall Employees
Active Employees
Attrition Count
Attrition Rate
Average Age
Department-wise Attrition
Education Field-wise Attrition
Age Group Distribution
Job Satisfaction Analysis
Gender-wise Attrition Analysis

Key Insights-

Yahan tumhare dashboard ke according likh sakti ho:
Overall Attrition Rate is 16.12%
R&D department recorded the highest employee attrition.
Employees aged 25–34 form the largest workforce.
Life Sciences employees experienced the highest attrition among education fields.
Attrition patterns vary across age groups and gender.
Job satisfaction differs across different job roles.
